## 🚀 Featured Projects

### 🤖 RecallAI — Conversational RAG Backend

A conversational RAG application for querying PDF documents using natural language.

**Built with:** Python • FastAPI • PostgreSQL • pgvector • SQLAlchemy • LangChain • Hugging Face • Ollama

- PDF ingestion and document processing
- Embedding generation and vector storage
- Multi-stage retrieval with similarity search and reranking
- Persistent multi-turn conversations
- JWT authentication and authorization
- Source citations for generated responses
- RAG evaluation for retrieval and response quality

---

### 🔗 WebhookHub — Webhook Delivery Platform

A multi-tenant webhook delivery platform focused on reliable asynchronous event processing.

**Built with:** Python • FastAPI • PostgreSQL • SQLAlchemy • Redis • Celery • Docker

- Multi-tenant webhook subscriptions and event routing
- Asynchronous event delivery using Celery workers
- Retry handling with exponential backoff
- Idempotency and concurrency control
- Delivery tracking, failure recovery and event replay
- HMAC-SHA256 request signing
- SSRF protection and rate limiting
- Docker-based development and deployment setup
